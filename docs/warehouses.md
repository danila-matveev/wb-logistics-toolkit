## Как обновить справочник

`warehouse_status.yaml` — конфигурационный файл, обновляется вручную:

1. **Склад открылся/закрылся:** обновите поле `available` и `reason`
2. **Изменился лимит:** обновите `redistribution_limit_per_day` из WB Partners → Тарифный конструктор
3. **Новый склад:** добавьте новую запись, укажите `fd` (ФО) и лимит

Лимиты берутся из **WB Partners → Тарифный конструктор** — раздел распределения поставок.

Алгоритм перестановок читает лимиты из этого файла при каждом запуске.
